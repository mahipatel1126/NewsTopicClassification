# 📰 AI News Topic Classification

## Project Overview
This project classifies news articles into four categories using a fine-tuned DistilBERT Transformer model.

Categories:
- 🌍 World
- ⚽ Sports
- 💼 Business
- 💻 Sci/Tech

---

## Dataset

AG News Dataset

Classes:
- World
- Sports
- Business
- Sci/Tech

---

## Model

- DistilBERT
- Hugging Face Transformers
- Fine-tuned on AG News

---

## Performance

Accuracy : 88.02%

F1 Score : 88.05%

---

## Features

- AI-based Classification
- Confidence Score
- Probability Visualization
- Prediction History
- CSV Download
- Example Articles
- Professional Streamlit UI
